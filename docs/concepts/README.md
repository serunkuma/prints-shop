# Concepts — Design Philosophy & Rationale

Status: Current

This directory answers the "why" questions about Kumachi Prints. Every document here explains a design philosophy, a core belief, or a trade-off that shaped the project.

**What belongs here:**
- Design philosophy and principles
- Business rationale for architectural decisions
- Domain definitions and conceptual models
- Content strategy and brand positioning
- Trade-off analyses

**What does NOT belong here:**
- Implementation details (go in `docs/system/`)
- Data structures and field definitions (go in `docs/data/`)
- Task checklists and timelines (go in `docs/planning/`)
